Arena battles, right in your browser.

Play the story or create a local battle against bots. Your browser runs both the game and its local server.

The first launch downloads approximately 514 MiB of game assets. Use a desktop browser with WebGL 2 and a keyboard or controller; loading may take a few minutes.

Start a game

Keep the default local host and choose Single for the story. For an arena battle, choose Multi, create a game and add at least two bots.

Controls

Click the game to focus. Move with the arrow keys, place bombs with Space, and leave a game with Esc. Controllers are supported too.

Play online

This page runs local games in your tab. To play with friends on other devices, connect to a separately hosted game server. Online setup
